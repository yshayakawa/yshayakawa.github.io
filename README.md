# yshayakawa.github.io

Personal website of Yuichi S. Hayakawa (Jekyll / GitHub Pages, prototype).

- Layout and style: `_layouts/default.html`, `assets/css/style.css` (modelled on the legacy CSIS page)
- Menu: `_data/nav.yml`
- Contact form: set `formspree_id` in `_config.yml` after creating a form at https://formspree.io/
- Pages: `*.md` in the repository root (the English and Japanese text sit side by side)
